## 1. Project Overview

### Vision

LUXOR es una aplicación móvil para Android que conecta creadores de contenido (música, conciertos, contenido sensual no explícito) con suscriptores en Perú. Los usuarios compran **Diamantes** con dinero real vía Culqi y los gastan para desbloquear videos, fotos y acceso al Telegram de cada creadora.

La plataforma opera como una economía de moneda virtual estilo TikTok Coins: pago por contenido específico, sin suscripción mensual obligatoria.

### Goals
- Que creadores puedan subir y monetizar su contenido en menos de 5 minutos
- Que suscriptores compren Diamantes y desbloqueen contenido en menos de 3 taps
- MVP funcional en 7 días con distribución vía APK directo

### Success Metrics
- Un creador publica su primer contenido en menos de 5 minutos
- Un suscriptor compra Diamantes y desbloquea contenido en menos de 2 minutos
- Zero crashes en el flujo crítico: comprar → desbloquear → ver contenido

## 2. Tech Stack

| Capa | Tecnología | Por qué |
|------|-----------|---------|
| Framework | Flutter 3.x (Dart) | Mejor performance para apps con video, control visual total |
| Estado | Riverpod 2.x | Estándar moderno de Flutter, testeable, sin boilerplate |
| Navegación | GoRouter | Declarativo, deep linking, auth guard integrada |
| Backend | Node.js + Express | API REST con PostgreSQL |
| Base de datos | PostgreSQL 14+ | Schema existente en Backend/src/database/init.sql |
| Videos | Bunny.net Stream | CDN económico con HLS, latencia óptima en LATAM |
| Pagos | Culqi | Procesador peruano #1, acepta PEN, Visa/MC/Yape |
| Imágenes | Cloudinary | Upload y CDN de imágenes |
| Auth | JWT | Tokens con expiry 24h, refresh token 7 días |
| Fuentes | google_fonts | Lexend + Be Vietnam Pro |
| Distribución | APK directo + Play Store (18+) | iOS excluido del MVP |

```
Production: https://api.luxor.app
```

### Authentication
- JWT en header: `Authorization: Bearer <access_token>`
- Token expiry: 24h
- Refresh token: 7 días

| GET | `/api/home/feed?category=x` | Feed filtrado | Sí |
| POST | `/api/subscriptions` | Crear suscripción | Sí |

### Response Format

```json
// Success
{
  "success": true,
  "data": { ... }
}

// Error
{
  "success": false,
  "error": "ERROR_CODE",
  "message": "Descripción"

```

### Repositories (Flutter → HTTP)

```dart
// auth_repository.dart
- POST /api/auth/register → { email, password, name, phone, dateOfBirth }
```

## 8. Authentication & Authorization

### Auth Flow

```
Registro:
  1. RegisterScreen: email + password + name + phone + dateOfBirth
  2. POST /api/auth/register
  3. Backend crea usuario
  4. OnboardingScreen para creators (username, bio, YAPE)

Login:
  1. LoginScreen: email/password
  2. POST /api/auth/login
  3. Backend retorna { accessToken, refreshToken, user }
  4. GoRouter redirige a /home

Token Storage:
  flutter_secure_storage
  Refresh automático cuando expira
```

### Protected Routes

```dart
// GoRouter redirect
redirect: (context, state) {
  final token = storage.read('accessToken');
  final isAuth = token != null && !isTokenExpired(token);
  
  if (!isAuth && !isAuthRoute) return '/login';
  if (isAuth && isAuthRoute) return '/home';
  return null;
}
```

### Roles

| Rol | Puede hacer |
|-----|-------------|
| subscriber | Ver contenido, comprar Diamantes, desbloquear contenido |
| creator | Todo lo de subscriber + subir contenido, ver dashboard, earnings |

## 16. Reglas No Negociables

1. **Un archivo por widget/screen.** Máximo 300 líneas.
2. **Backend es la fuente de verdad.** Todas las operaciones de wallet pasan por API.
3. **Dark mode único.** No hay modo light.
4. **Riverpod para todo el estado.** Sin setState.
5. **Nunca commitear .env.**
6. **El wallet nunca puede quedar en negativo.** Backend valida.
7. **Videos a Bunny.net, imágenes a Cloudinary.**
8. **Comisión: 70% creadora / 30% plataforma** (lógica en backend).
9. **APK mínimo Android 5.0.**
10. **Tokens nunca en código.** Usar .env.
